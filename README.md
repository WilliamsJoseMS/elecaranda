# ElecAranda - Plataforma Educativa ELEE0310

Una aplicación web interactiva y responsiva diseñada para el certificado de profesionalidad **ELEE0310 (Montaje y Mantenimiento de Instalaciones Eléctricas de Baja Tensión)**.

![ElecAranda Preview](https://images.unsplash.com/photo-1581092334651-ddf26d9a1930?q=80&w=1200&auto=format&fit=crop)

## 🚀 Características

- **Gestión de Almacén**: Zonificación interactiva, control de stock y tipos de almacenamiento.
- **Planificación de Obras**: Diagramas de Gantt, PERT y método de la ruta crítica (CPM).
- **Documentación Técnica**: Generación de presupuestos, calculadoras de precios descompuestos y normativa REBT.
- **Pruebas y Verificación**: Protocolos paso a paso para ensayos de aislamiento, tierra y diferenciales.
- **Simbología Interactiva**: Galería completa bajo norma UNE-EN-60617.
- **Autoevaluación**: Banco de preguntas dinámico para repasar conceptos clave.

## 🛠️ Tecnologías

- **React + Vite**
- **Tailwind CSS**
- **Lucide Icons**
- **Motion (Framer Motion)** para animaciones.

## 💻 Instalación Local

1. Clona el repositorio:
   ```bash
   git clone https://github.com/TU_USUARIO/elecaranda.git
   ```
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Ejecuta el servidor de desarrollo:
   ```bash
   npm run dev
   ```
